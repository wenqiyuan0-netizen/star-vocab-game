# Goethe 预设词库

本目录包含从歌德学院官方词汇表提取的预设词库，可直接导入到 Vocab Master 中使用。

## 文件说明

### 1. 按等级分类的词库

- **goethe-a1.txt** (555 个单词)
  - 歌德学院 A1 等级词汇表
  - 适合德语初学者

- **goethe-a2.txt** (1,310 个单词)
  - 歌德学院 A2 等级词汇表
  - 适合有一定基础的学习者

- **goethe-b1.txt** (2,863 个单词)
  - 歌德学院 B1 等级词汇表
  - 适合中级学习者

### 2. 合并词库

- **goethe-all.txt** (3,933 个单词)
  - 包含 A1-B1 所有等级的词汇
  - 已进行全局去重

## 使用方法

### 方法一：使用预设词库功能（推荐）

1. 打开应用，进入【词库】页面
2. 点击右上角的 **"预设词库"** 按钮
3. 在弹出的窗口中选择想要导入的等级
4. 点击 **"导入"** 按钮即可

### 方法二：手动复制粘贴

1. 用文本编辑器打开对应的 `.txt` 文件
2. 复制文件内容
3. 打开应用，进入【词库】页面
4. 在 **"添加新词"** 区域粘贴内容
5. 点击 **"添加"** 按钮

## 文件格式

每个文件都采用简单的文本格式，每行一个单词：

```
德语单词;中文翻译
```

示例：
```
ab;从...起
aber;但是, 可是
die Abfahrt;出发, 启程
abgeben;交出, 递交
```

## 特点

- **自动去重**：导入时会自动过滤已存在的单词
- **包含冠词**：名词自动带有冠词（der/die/das）
- **完整翻译**：包含准确的中文翻译
- **官方来源**：基于歌德学院官方词汇表

## 数据来源

所有词汇数据来源于歌德学院（Goethe-Institut）官方发布的分级词汇表，经过提取和格式化处理。

## 技术说明

这些文件由 `scripts/convertGoetheVocab.js` 脚本自动生成，该脚本从原始 JSON 格式的词汇表中提取单词和翻译。

如需重新生成这些文件，运行：
```bash
node scripts/convertGoetheVocab.js
```

## 建议学习路径

1. **初学者（零基础）**：从 A1 开始
2. **有基础（掌握基本对话）**：从 A2 开始
3. **中级学习者**：学习 B1 词汇
4. **系统学习**：按 A1 → A2 → B1 顺序逐级学习
