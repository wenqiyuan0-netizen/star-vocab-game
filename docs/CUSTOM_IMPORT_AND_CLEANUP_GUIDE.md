# 自定义导入与删除未学习单词功能指南

## 功能概述

在【词库】页面的【添加新词】区域，现在有三个按钮：

1. **添加** - 导入输入框中的单词（原有功能）
2. **预设词库** - 从歌德词汇表导入单词（新增）
3. **删除未学习** - 删除所有未开始学习的单词（新增）

## 使用方法

### 1. 预设词库导入

#### 操作步骤：

**第一次点击**：
- 点击 **"预设词库"** 按钮
- 按钮变色（亮色），表示已激活
- 其他按钮的激活状态会被取消

**第二次点击**：
- 再次点击已激活的 **"预设词库"** 按钮
- 弹出词库选择窗口
- 选择想要的等级（A1/A2/B1/全部）
- 点击"导入"

#### 特点：
- ✅ 自动去重
- ✅ 包含冠词（der/die/das）
- ✅ 完整翻译
- ✅ 来自歌德官方词汇表

### 2. 删除未学习单词

#### 操作步骤：

**第一次点击**：
- 点击 **"删除未学习"** 按钮
- 按钮变色（红色），表示已激活
- 其他按钮的激活状态会被取消

**第二次点击**：
- 再次点击已激活的 **"删除未学习"** 按钮
- 弹出确认对话框
- 显示将删除的单词数量
- 点击"确认删除"执行

#### 删除规则：

**会被删除的单词**：
- `state === 'new'` 且 `lastReview === null/0`
- 即：从未开始学习的新单词

**会被保留的单词**：
- 已经复习过至少一次（`lastReview > 0`）
- 学习状态不是 'new' 的单词
- 包括所有正在学习、已毕业的单词

#### 示例：

假设你的词库中有：
- 100 个新单词（从未复习）
- 50 个学习中的单词（复习过 1-5 次）
- 30 个已毕业的单词

点击"删除未学习"后：
- ❌ 删除：100 个新单词
- ✅ 保留：50 个学习中 + 30 个已毕业 = 80 个单词

## 交互设计

### 按钮状态

| 状态 | 外观 | 说明 |
|------|------|------|
| 未激活 | 半透明，淡色 | 等待第一次点击 |
| 已激活 | 高亮，有光圈 | 准备执行操作 |
| 执行中 | 弹出对话框/选择器 | 正在处理 |

### 互斥逻辑

- 同时只能有一个按钮处于激活状态
- 点击一个按钮会自动取消其他按钮的激活

### 安全设计

- **二次确认**：点击两次才能执行
- **明确提示**：确认对话框会详细说明操作后果
- **可撤销**：对话框中有"取消"按钮

## 使用场景

### 场景 1：快速开始学习歌德词汇

1. 打开【词库】页面
2. 点击顶部的 **"➕ 增加新词"** 图标展开添加面板
3. 点击 **"预设词库"** 按钮（第一次点击激活）
4. 再次点击 **"预设词库"** 按钮（第二次点击打开选择器）
5. 选择 "Goethe A1 词汇"
6. 点击"导入"
7. 开始学习

### 场景 2：清理未使用的单词

你可能在试用时导入了大量单词，但实际只学习了一部分：

1. 打开【词库】页面
2. 展开添加面板
3. 点击 **"删除未学习"** 按钮（第一次点击激活，按钮变红）
4. 再次点击 **"删除未学习"** 按钮（第二次点击弹出确认）
5. 确认删除
6. 词库现在只保留已学习的单词

### 场景 3：导入并清理

适合从头开始学习：

1. 点击 **"删除未学习"** → 确认（清空未学习的旧单词）
2. 点击 **"预设词库"** → 选择 A1 → 导入（添加新词汇）
3. 开始系统学习

## 技术实现

### 按钮激活逻辑

```javascript
// 第一次点击：激活
if (!buttonActive) {
  setButtonActive(true);
  setOtherButtonActive(false); // 互斥
}
// 第二次点击：执行
else {
  executeAction();
  setButtonActive(false);
}
```

### 删除过滤逻辑

```javascript
// 筛选未学习的单词
const unlearnedWords = globalWordDb.filter(w =>
  w.state === 'new' &&
  (!w.lastReview || w.lastReview === 0 || w.lastReview === null)
);

// 保留已学习的单词
const learnedWords = globalWordDb.filter(w =>
  w.state !== 'new' ||
  (w.lastReview && w.lastReview > 0)
);

// 更新词库
setGlobalWordDb(learnedWords);
```

## 常见问题

### Q: 误点了两次按钮怎么办？
A: 如果是"删除未学习"，在确认对话框中点击"取消"即可。如果是"预设词库"，关闭选择器窗口即可。

### Q: 删除后可以恢复吗？
A: 不能。删除是永久性的。建议在删除前先导出存档（点击"存档"按钮）。

### Q: 为什么要点击两次？
A: 这是安全设计，防止误操作。第一次点击激活按钮，第二次点击才真正执行。

### Q: 按钮变色后如何取消？
A: 点击其他按钮，或者点击添加面板外的区域（关闭面板）会自动取消激活状态。

### Q: "删除未学习"会删除导入的预设词库吗？
A: 是的。如果导入后没有开始学习，这些单词会被删除。建议先学习一部分，再删除其他未学习的单词。

### Q: 如何判断单词是否"已学习"？
A: 系统根据两个条件判断：
- `lastReview > 0`（至少复习过一次）
- 或 `state !== 'new'`（学习状态不是"新词"）

## 最佳实践

### ✅ 推荐做法

1. **导入前去重**：先删除未学习的单词，再导入新词库
2. **分批导入**：先导入 A1，学完后再导入 A2
3. **定期清理**：每周删除一次未学习的单词，保持词库整洁
4. **备份数据**：重要操作前先导出存档

### ❌ 不推荐做法

1. ~~一次性导入所有等级~~ → 容易造成词库过大，难以管理
2. ~~导入后立即删除~~ → 浪费操作，应该先学习
3. ~~不看确认对话框直接点~~ → 可能误删重要数据
